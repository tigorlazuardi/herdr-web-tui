Design & reference docs for **herdr-web-tui**: a thin web frontend that renders the
Herdr TUI in a browser and adds an atomic artifact promptbox.

- **Guides** — running the binary, the nginx gateway, environment/flags, systemd.
- **Reference** — the `/send`, `/clientlog`, and `/ws` endpoint contracts.
- **Design decisions** — long-lived architecture choices.
- **Reports** — lessons learnt from bugs, vendor quirks, incidents. See [Index of Reports](/herdr-web-tui/reports/).

Working plans (`plans/**` at repo root) use the same MDX dialect but are not
published here.
