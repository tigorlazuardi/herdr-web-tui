---
title: Herdr Web TUI
description: Operator and API documentation for herdr-web-tui, a thin browser frontend for a running Herdr server.
---

**herdr-web-tui** is a thin web frontend that renders the Herdr TUI in a browser
and adds an atomic artifact promptbox for getting files into a pane. It ships as
one static Go binary with the frontend embedded — nothing else to deploy.

- **Guides** — Nix flake install (Home Manager), running the binary, the nginx gateway, environment/flags, systemd.
- **Reference** — the `/send`, `/clientlog`, and `/ws` endpoint contracts.
